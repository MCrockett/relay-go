# Owner rules

Judgment rules for every relay stage and review, in every project. One line each: date, rule, reason. Add with `relay rule --global`.

This is an example. Your own rules live in `~/.relay/RULES.md`; a project's rules live in its `docs/relay/RULES.md`.

- 2026-01-01: Plain English in all copy and docs; no stock AI phrasing. (Example: a writing preference for every project.)
- 2026-01-01: One open PR per repo. Do not start another feature while one has an open, unmerged PR. (Example: a workflow rule.)
